# Golden decoder fixtures

Used by `tests/golden.rs`. Every file is listed with its SHA-256 in `SHA256SUMS`, and the test
fails when a file changes. Each file is under 200 KB.

## Licence

All files were made for this repository from signals generated by its own test code (no
third-party recording), and are under the repository's licence (`LICENSE`).

## How they were made

Sources, 48 kHz stereo, 12 000 frames (0.25 s), written as PCM WAV by the test helpers in
`tests/common/`:
- `src-16.wav`, `src-24.wav`: `test_signal(16, 12_000)` and `test_signal(24, 12_000)`, the
  signal of the existing WAV fixture in `bit_exact.rs`.
- `tone-16.wav`: `fixtures::tone_i16(48_000, 2, 12_000, 440.0)`.

Converted with FFmpeg `N-127043-g5a54fcf75e-20260930` (the commands reproduce the committed
bytes exactly):

| File | Command |
|---|---|
| `alac-16.m4a` | `ffmpeg -i src-16.wav -c:a alac -map_metadata -1 -fflags +bitexact -flags:a +bitexact alac-16.m4a` |
| `alac-24.m4a` | `ffmpeg -i src-24.wav -c:a alac -map_metadata -1 -fflags +bitexact -flags:a +bitexact alac-24.m4a` |
| `aiff-16.aiff` | `ffmpeg -i src-16.wav -map_metadata -1 -fflags +bitexact aiff-16.aiff` |
| `aiff-24.aiff` | `ffmpeg -i src-24.wav -c:a pcm_s24be -map_metadata -1 -fflags +bitexact aiff-24.aiff` |
| `vorbis-tone.ogg` | `ffmpeg -i tone-16.wav -c:a libvorbis -q:a 4 -map_metadata -1 -fflags +bitexact -flags:a +bitexact vorbis-tone.ogg` |
| `vorbis-tone-ref.s16` | `ffmpeg -c:a libvorbis -i vorbis-tone.ogg -f s16le vorbis-tone-ref.s16` (libvorbis reference decode, 16-bit little-endian) |

The Ogg file's last page has granule position 12 000, so a correct decode is 12 000 frames.
FFmpeg's Ogg reader drops the last 128 of them, so the reference holds 11 872 frames; the test
compares those and checks the length against the granule position.
